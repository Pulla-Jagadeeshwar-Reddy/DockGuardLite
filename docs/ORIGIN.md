# Origin

This repository is derived from the full DocuGuard repository at commit `9d0010b` on branch `pull/final-integration-fixes`. The full version is kept separately in the original repository, which this work does not modify.

The lite version is being simplified around the 11-entity ER model under `docs/inputs/`: document policy workflows, authentication and role/document access, audit and emergency access, and reading acknowledgments remain. The plan removes the full version's additional search/vector, notification, regulatory coverage, similar-document, and dependency-graph functionality. See `SIMPLIFICATION.md` and `SIMPLIFICATION_PLAN.md` for the approved scope and decisions.
