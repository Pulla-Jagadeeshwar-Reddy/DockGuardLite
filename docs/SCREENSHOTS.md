# Screenshot Capture Checklist

Capture genuine screenshots from the running lite application after implementation and verification. No screenshots are included or fabricated here.

1. Login page with validation state.
2. Admin dashboard with document status, expiry and access activity.
3. Document list filtered to a role-permitted policy set.
4. Upload form with selected synthetic PDF/DOCX before submission.
5. Document detail showing pending approval and version history.
6. A different Admin reviewing and approving that version.
7. My Policies showing pending assignments, then acknowledged current version.
8. Admin acknowledgment completion by department.
9. Doctor/Nurse emergency access form with required justification.
10. Admin emergency review queue with one pending request.
11. Audit log filters and an intact chain verification result.
12. MongoDB content analytics widget if approved and implemented.
13. A role access comparison showing a permitted and denied document.

Do not capture or expose `.env`, private uploaded files, or real personal/health information.
